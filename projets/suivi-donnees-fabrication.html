Suivi de données de fabrication

Un projet de traitement de données publiques de fabrication pour organiser, contrôler et analyser des mesures de production.

Ce projet est à venir. Cette page présente l'idée et la démarche prévue ; elle sera complétée avec le code et les résultats.

Objectif

Rapprocher mon expérience en ingénierie des procédés et le data engineering : partir de mesures de production brutes et en faire des indicateurs fiables pour suivre la qualité et la performance d'une fabrication.

Les données

Le projet s'appuiera sur un jeu de données public de fabrication : relevés de capteurs, paramètres de procédé et résultats de contrôle. Le choix précis du jeu de données sera indiqué ici.

Les étapes prévues

  1. Collecte (couche Bronze). Chargement des mesures de production brutes, sans modification.
  2. Contrôle et normalisation (couche Silver). Vérification de la qualité des mesures (valeurs aberrantes, trous, unités), puis mise au même format.
  3. Indicateurs (couche Gold). Calcul d'indicateurs de production prêts à être affichés : taux de conformité, dérives, tendances.
  4. Tableau de bord. Restitution dans Power BI pour suivre la production en un coup d'œil.

Pourquoi ces technologies

  • Python pour le chargement et les contrôles qualité
  • SQL pour structurer les données et calculer les indicateurs
  • Power BI, l'outil de tableau de bord le plus répandu en entreprise
