# Sabeur Jedid — portfolio

Portfolio statique (HTML, CSS et JavaScript sans framework) consacré au Data Engineering, à l'IA et à l'automatisation. Publié avec GitHub Pages : https://kepsilone.github.io/

## Structure

- `index.html` : page unique (accueil, à propos, projets, parcours, compétences, contact)
- `assets/css/style.css` : styles
- `assets/js/main.js` : animations d'apparition, menu rapide (Ctrl/⌘ + K), cadres projet, copie de l'e-mail
- `assets/img/` : photo, logo et favicon
- `robots.txt`, `sitemap.xml` : référencement

## Modifier le contenu

Les textes sont directement dans `index.html`. La source de travail éditable est le fichier `contenu-site.md` (hors dépôt).

## Test en local

```
python -m http.server 8000
```

Puis ouvrir http://localhost:8000.
