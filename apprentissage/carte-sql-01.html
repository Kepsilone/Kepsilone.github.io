01 — SQL : les fondamentaux

Objectif : lire, filtrer, trier et modifier des données.

Une étape à la fois : la question, les 2 ou 3 commandes à connaître, un exemple et un tips.

Lire

facile

Je veux voir certaines colonnes d'une table.

J'écris
  • SELECT→choisir les colonnes
  • FROM→dire quelle table
  • DISTINCT→enlever les doublons
Exemple 
SELECT nom, pays
FROM clients;

Tips : DISTINCT porte sur toutes les colonnes choisies, pas sur une seule.

Aller plus loin
SELECT * AS alias
2

Trier

facile

Je veux classer les lignes et n'en garder que quelques-unes.

J'écris
  • ORDER BY … DESC→trier, du plus grand au plus petit
  • LIMIT 3→garder 3 lignes
Exemple 
SELECT nom, score
FROM clients
ORDER BY score DESC
LIMIT 3;

Tips : en DESC, les NULL arrivent en premier. Ajoutez NULLS LAST.

Aller plus loin
ASC NULLS LAST OFFSET
3

Filtrer

moyen

Je veux garder seulement les lignes qui m'intéressent.

J'écris
  • WHERE→poser une condition
  • = <> > <→comparer
  • AND / OR→combiner
Exemple 
SELECT *
FROM clients
WHERE pays = 'France'
  AND score > 400;

Tips : = NULL ne marche jamais. Écrivez IS NULL.

Aller plus loin
IN (…) BETWEEN LIKE 'A%' ILIKE IS NULL NOT
4

Transformer

moyen

Je veux calculer ou nettoyer une valeur.

J'écris
  • + - * /→calculer (nombres)
  • UPPER / TRIM→nettoyer (texte)
  • COALESCE→remplacer un NULL
Exemple 
SELECT UPPER(nom),
       score * 1.1
FROM clients;

Tips : entre deux entiers, 5 / 2 donne 2. Écrivez 5 / 2.0.

Aller plus loin
LOWER LENGTH || ROUND CASE WHEN ::TEXT ::INTEGER
5

Modifier

avancé

Je veux ajouter, changer ou supprimer des lignes.

J'écris
  • INSERT INTO→ajouter
  • UPDATE … SET→modifier
  • DELETE FROM→supprimer
Exemple 
UPDATE clients
SET score = 450
WHERE id = 3;

Tips : sans WHERE, toutes les lignes sont touchées. Testez d'abord avec un SELECT.

Aller plus loin
VALUES WHERE id = …
6

Créer

avancé

Je veux créer une table propre.

J'écris
  • CREATE TABLE→créer la table
  • INTEGER / TEXT→choisir le type
  • PRIMARY KEY→identifiant unique
Exemple 
CREATE TABLE clients (
  id INTEGER PRIMARY KEY,
  nom TEXT NOT NULL
);

Tips : un code postal reste du TEXT, sinon '01000' devient 1000.

Aller plus loin
NUMERIC DATE BOOLEAN NOT NULL UNIQUE DEFAULT CHECK ALTER TABLE DROP TABLE
