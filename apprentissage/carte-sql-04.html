Ranger en couches

facile

Je veux séparer les données brutes des données propres.

J'écris
  • raw→brut, tout en texte
  • staging→contrôlé et typé
  • marts→prêt pour l'analyse
Exemple 
CREATE SCHEMA raw;
CREATE SCHEMA staging;
CREATE SCHEMA marts;

Tips : en raw, tout est en TEXT : un fichier mal formé ne bloque jamais l'ingestion.

Ingérer

facile

Je veux charger un fichier CSV dans une table.

J'écris
  • \copy→fichier sur mon poste
  • COPY→fichier sur le serveur
Exemple 
\copy raw.ventes
FROM 'ventes.csv'
WITH (FORMAT csv, HEADER true)

Tips : ajoutez un raw_id : les lignes d'un même lot ont la même heure d'arrivée.

Contrôler

moyen

Je veux écarter les lignes invalides sans tout bloquer.

J'écris
  • IS NULL→valeur manquante
  • pg_input_is_valid→valeur convertible
Exemple 
SELECT * FROM raw.ventes
WHERE montant IS NULL
   OR NOT pg_input_is_valid(
        montant, 'numeric');

Tips : une regex seule laisse passer les NULL : testez-les à part.

Dédoublonner

moyen

Je veux une seule ligne par événement.

J'écris
  • ROW_NUMBER() OVER→numéroter les doublons
  • WHERE rn = 1→garder le premier
Exemple 
SELECT * FROM (
  SELECT *, ROW_NUMBER() OVER (
    PARTITION BY event_id
    ORDER BY raw_id DESC) AS rn
  FROM raw.ventes) t
WHERE rn = 1;

Tips : la dernière ligne reçue n'est pas forcément la dernière version.

Aller plus loin
ORDER BY version DESC ::NUMERIC ::DATE
5

Charger

avancé

Je veux insérer les nouvelles lignes et mettre à jour les anciennes.

J'écris
  • MERGE→insérer ou mettre à jour
  • RAISE EXCEPTION→tout arrêter si un contrôle échoue
Exemple 
MERGE INTO marts.ventes t
USING staging.ventes s
  ON t.id = s.id
WHEN MATCHED THEN UPDATE
  SET montant = s.montant
WHEN NOT MATCHED THEN INSERT
  VALUES (s.id, s.montant);

Tips : MERGE refuse une source qui contient deux fois la même clé.

Aller plus loin
ON CONFLICT IS DISTINCT FROM idempotence

Suivre dans le temps

avancé

Je veux traiter seulement les nouveautés et garder l'historique.

J'écris
  • watermark→reprendre là où on s'est arrêté
  • SCD Type 2→garder les anciennes versions
Exemple 
SELECT * FROM raw.ventes
WHERE raw_id > (
  SELECT MAX(to_raw_id)
  FROM ops.pipeline_runs);

Tips : le watermark n'avance qu'après un succès.

Aller plus loin
valid_from valid_to is_current CDC

Ordre d'un pipeline : ingérer → contrôler → dédoublonner → charger → vérifier → journaliser
Règle d'or : relancer le pipeline deux fois doit donner le même résultat
