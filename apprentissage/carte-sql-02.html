02 — SQL intermédiaire

Objectif : croiser, regrouper et transformer les données.

Une étape à la fois : la question, les 2 ou 3 commandes à connaître, un exemple et un tips.

1

Compter et calculer

facile

Je veux un total, une moyenne ou un nombre de lignes.

J'écris
  • COUNT(*)→compter les lignes
  • SUM / AVG→somme, moyenne
  • MIN / MAX→plus petit, plus grand
Exemple 
SELECT COUNT(*), AVG(score)
FROM clients;

Tips : COUNT(score) ignore les NULL, COUNT(*) les compte.

Aller plus loin
COUNT(DISTINCT x) ROUND(AVG(x), 2) STRING_AGG
2

Regrouper

facile

Je veux un résultat par catégorie.

J'écris
  • GROUP BY→un résultat par groupe
  • HAVING→filtrer les groupes
Exemple 
SELECT pays, COUNT(*)
FROM clients
GROUP BY pays
HAVING COUNT(*) > 1;

Tips : WHERE filtre les lignes avant, HAVING filtre les groupes après.

Aller plus loin
FILTER (WHERE …) ORDER BY COUNT(*) DESC
3

Joindre

moyen

Je veux combiner deux tables.

J'écris
  • JOIN … ON→garder ce qui correspond
  • LEFT JOIN→tout garder à gauche
Exemple 
SELECT c.nom, co.montant
FROM clients c
LEFT JOIN commandes co
  ON co.client_id = c.id;

Tips : un client avec 3 commandes apparaît 3 fois. Comptez avec COUNT(DISTINCT …).

Aller plus loin
FULL OUTER JOIN CROSS JOIN SELF JOIN USING (col)
4

Convertir

moyen

Je veux changer le type d'une valeur ou regrouper des dates.

J'écris
  • ::INTEGER / ::TEXT→convertir
  • DATE_TRUNC→ramener une date au mois
Exemple 
SELECT DATE_TRUNC('month', date_cmd)
FROM commandes;

Tips : 'abc'::INTEGER fait échouer toute la requête.

Aller plus loin
CAST(x AS type) TO_CHAR EXTRACT INTERVAL '7 days' SPLIT_PART
5

Imbriquer

avancé

Je veux utiliser le résultat d'une requête dans une autre.

J'écris
  • (SELECT …)→requête dans la requête
  • NOT EXISTS→ce qui n'a pas de correspondance
Exemple 
SELECT nom FROM clients
WHERE score >
  (SELECT AVG(score) FROM clients);

Tips : avec un NULL dans la liste, NOT IN ne renvoie rien. Utilisez NOT EXISTS.

Aller plus loin
EXISTS IN (SELECT …) FROM (SELECT …) AS t
6

Organiser

avancé

Je veux découper une longue requête en étapes lisibles.

J'écris
  • WITH … AS→nommer une étape
  • UNION ALL→empiler deux résultats
Exemple 
WITH top AS (
  SELECT * FROM clients
  WHERE score > 400
)
SELECT * FROM top;

Tips : UNION supprime les doublons, UNION ALL les garde et va plus vite.

Aller plus loin
CREATE VIEW UNION INTERSECT EXCEPT

Ordre d'écriture : SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
Ordre d'exécution : FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
