La règle à retenir en premier

Ordre d'écritureWITH → SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
Ordre d'exécutionFROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT

La base lit d'abord la table et filtre, puis choisit les colonnes. C'est pourquoi un alias créé dans SELECT n'existe pas encore dans le WHERE.

Niveau 1 · Les bases

Lire, filtrer, trier et nettoyer des données.

1

Lire

bases

Je veux afficher certaines colonnes d'une table.

J'écris
  • SELECT→choisir les colonnes
  • FROM→dire quelle table
  • DISTINCT→enlever les doublons
Exemple 
SELECT DISTINCT pays
FROM clients;

Tips : DISTINCT porte sur toutes les colonnes choisies, pas sur une seule.

Aller plus loin
SELECT * AS alias
2

Filtrer

bases

Je veux garder seulement certaines lignes.

J'écris
  • WHERE→poser une condition
  • = <> > < >= <=→comparer
  • AND / OR / NOT→combiner
Exemple 
SELECT * FROM clients
WHERE pays = 'France'
  AND score >= 430;

Tips : = NULL ne marche jamais. Écrivez IS NULL.

Aller plus loin
IN ('France', 'Spain') BETWEEN a AND b LIKE 'A%' ILIKE IS NOT NULL ( … ) pour AND / OR
3

Trier et limiter

bases

Je veux classer les lignes et n'en garder que quelques-unes.

J'écris
  • ORDER BY … DESC→trier
  • LIMIT / OFFSET→garder, sauter des lignes
Exemple 
SELECT nom, score FROM clients
ORDER BY score DESC, id
LIMIT 5;

Tips : ajoutez un second critère (id) : les égalités sortent toujours dans le même ordre.

Aller plus loin
ASC NULLS LAST
4

Conditions

bases

Je veux une valeur qui dépend d'une condition.

J'écris
  • CASE WHEN … THEN→si … alors
  • COALESCE→remplacer un NULL
  • NULLIF→transformer une valeur en NULL
Exemple 
SELECT nom,
  CASE WHEN score >= 450 THEN 'haut'
       ELSE 'autre' END
FROM clients;

Tips : montant / NULLIF(quantite, 0) évite la division par zéro.

Aller plus loin
CASE dans WHERE CASE dans ORDER BY
5

Fonctions utiles

bases

Je veux nettoyer du texte ou arrondir un nombre.

J'écris
  • UPPER / LOWER / TRIM→texte
  • ROUND / ABS→nombres
  • ::NUMERIC→convertir
Exemple 
SELECT UPPER(TRIM(nom)),
       ROUND(score * 1.1, 1)
FROM clients;

Tips : entre deux entiers, 5 / 2 donne 2. Écrivez 5 / 2.0.

Aller plus loin
LENGTH SUBSTRING REPLACE CONCAT || CAST(x AS type)
6

Modifier

bases

Je veux ajouter, changer ou supprimer des lignes.

J'écris
  • INSERT INTO … VALUES→ajouter
  • UPDATE … SET→modifier
  • DELETE FROM→supprimer
Exemple 
UPDATE clients
SET score = 450
WHERE id = 3;

Tips : sans WHERE, toutes les lignes sont touchées. Testez d'abord avec un SELECT.

Aller plus loin
INSERT … SELECT RETURNING *

Niveau 2 · Intermédiaire

Compter, regrouper, croiser les tables et découper les requêtes.

7

Agréger et regrouper

intermédiaire

Je veux un total ou une moyenne par catégorie.

J'écris
  • COUNT / SUM / AVG→compter, additionner, moyenne
  • GROUP BY→un résultat par groupe
  • HAVING→filtrer les groupes
Exemple 
SELECT pays, AVG(score)
FROM clients
WHERE score <> 0
GROUP BY pays
HAVING AVG(score) > 430;

Tips : WHERE filtre les lignes avant le calcul, HAVING filtre les groupes après.

Aller plus loin
MIN / MAX COUNT(DISTINCT x) STRING_AGG(x, ', ')
8

Joindre

intermédiaire

Je veux combiner deux tables.

J'écris
  • JOIN … ON→garder ce qui correspond
  • LEFT JOIN→tout garder à gauche
Exemple 
SELECT c.nom, co.montant
FROM clients c
LEFT JOIN commandes co
  ON co.client_id = c.id;

Tips : un filtre sur la table de droite se met dans ON pour garder les clients sans commande.

Aller plus loin
RIGHT JOIN FULL OUTER JOIN CROSS JOIN SELF JOIN
9

Dates

intermédiaire

Je veux regrouper ou calculer avec des dates.

J'écris
  • DATE_TRUNC('month', d)→ramener au mois
  • EXTRACT(YEAR FROM d)→garder une partie
Exemple 
SELECT DATE_TRUNC('month', date_cmd),
       SUM(montant)
FROM commandes
GROUP BY DATE_TRUNC('month', date_cmd);

Tips : triez sur la date, pas sur un nom de mois : « avril » passerait avant « janvier ».

Aller plus loin
CURRENT_DATE NOW() + INTERVAL '7 days'
10

Sous-requêtes

intermédiaire

Je veux utiliser le résultat d'une requête dans une autre.

J'écris
  • (SELECT …)→requête dans la requête
  • EXISTS / NOT EXISTS→y a-t-il une correspondance ?
Exemple 
SELECT nom FROM clients
WHERE score >
  (SELECT AVG(score) FROM clients);

Tips : avec un NULL dans la liste, NOT IN ne renvoie rien. Utilisez NOT EXISTS.

Aller plus loin
FROM (SELECT …) AS t ANY ALL
11

CTE : WITH

intermédiaire

Je veux découper une longue requête en étapes lisibles.

J'écris
  • WITH nom AS (…)→nommer une étape
  • , nom2 AS (…)→enchaîner plusieurs étapes
Exemple 
WITH top AS (
  SELECT * FROM clients
  WHERE score > 400
)
SELECT * FROM top;

Tips : WITH se place avant le SELECT principal.

Aller plus loin
WITH RECURSIVE
12

Empiler des résultats

intermédiaire

Je veux mettre deux résultats l'un sous l'autre.

J'écris
  • UNION ALL→empiler, doublons gardés
  • UNION→empiler, sans doublons
Exemple 
SELECT id FROM clients
UNION
SELECT client_id FROM commandes;

Tips : les deux requêtes doivent avoir le même nombre de colonnes, de types compatibles.

Fonctions de fenêtre

avancé

Je veux un rang ou un cumul sans regrouper les lignes.

J'écris
  • ROW_NUMBER() OVER→numéroter
  • PARTITION BY→recommencer par groupe
  • LAG / SUM() OVER→ligne d'avant, cumul
Exemple 
SELECT nom, pays,
  RANK() OVER (
    PARTITION BY pays
    ORDER BY score DESC)
FROM clients;

Tips : pour garder seulement le n° 1, passez par une CTE (WITH).

Aller plus loin
DENSE_RANK LEAD ROWS BETWEEN …
14

Créer une table

avancé

Je veux créer une table propre et protégée.

J'écris
  • CREATE TABLE→créer
  • PRIMARY KEY→identifiant unique
  • REFERENCES→lien vers une autre table
Exemple 
CREATE TABLE ventes (
  id INTEGER PRIMARY KEY,
  client_id INTEGER
    REFERENCES clients(id),
  montant NUMERIC(12,2)
    CHECK (montant >= 0)
);

Tips : DROP supprime la table, TRUNCATE la vide. Les deux sont sans retour.

Aller plus loin
ALTER TABLE NOT NULL UNIQUE DEFAULT CHECK
15

Insérer ou mettre à jour

avancé

Je veux ajouter une ligne, ou la mettre à jour si elle existe.

J'écris
  • ON CONFLICT … DO UPDATE→UPSERT
  • RETURNING→voir les lignes touchées
Exemple 
INSERT INTO clients (id, nom, score)
VALUES (1, 'alpha', 520)
ON CONFLICT (id)
DO UPDATE SET score = EXCLUDED.score;

Tips : il faut une clé primaire ou une contrainte UNIQUE sur la colonne visée.

Aller plus loin
EXCLUDED DO NOTHING
16

Transactions

avancé

Je veux pouvoir tout annuler si ça se passe mal.

J'écris
  • BEGIN … COMMIT→valider en bloc
  • ROLLBACK→tout annuler
Exemple 
BEGIN;
UPDATE comptes SET solde = solde - 100
WHERE id = 1;
ROLLBACK;

Tips : tant que COMMIT n'est pas lancé, rien n'est enregistré.

Aller plus loin

Tout ensemble

Voir un exemple complet qui combine CTE, jointure, agrégats et classement 
WITH scores AS (
  SELECT pays, AVG(score) AS moyenne, COUNT(*) AS nb
  FROM clients
  WHERE score <> 0
  GROUP BY pays
),
ventes AS (
  SELECT c.pays, SUM(co.montant) AS total
  FROM clients c
  JOIN commandes co ON co.client_id = c.id
  GROUP BY c.pays
)
SELECT s.pays,
       s.nb,
       ROUND(s.moyenne, 2) AS moyenne,
       COALESCE(v.total, 0) AS total,
       RANK() OVER (ORDER BY COALESCE(v.total, 0) DESC) AS rang
FROM scores s
LEFT JOIN ventes v ON v.pays = s.pays
ORDER BY total DESC
LIMIT 10;

Les scores et les ventes sont calculés séparément avant la jointure : sinon, un client avec plusieurs commandes compterait plusieurs fois dans la moyenne.

Ce mémento couvre le SQL utile au quotidien. Il ne liste pas toute la norme (JSON, tableaux, déclencheurs, procédures, partitionnement…).
